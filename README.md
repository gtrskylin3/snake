# Snake Game (C + ncurses)

Консольная реализация классической игры «Змейка» на языке C с использованием библиотеки **ncurses**.
[IMAGE](image.png)

## Возможности

* Управление змейкой с клавиатуры
* Рост змейки при поедании еды
* Подсчет очков
* Проверка столкновений:

  * со стенами
  * с собственным телом
* Цветной интерфейс через `ncurses`

## Управление

| Клавиша | Действие |
| ------- | -------- |
| W / ↑   | Вверх    |
| S / ↓   | Вниз     |
| A / ←   | Влево    |
| D / →   | Вправо   |

## Обозначения на поле

| Символ | Значение |
| ------ | -------- |
| `@`    | Змейка   |
| `$`    | Еда      |
| `#`    | Стена    |

## Требования

* GCC
* Библиотека ncurses
* Linux / WSL / Unix-подобная система

### Установка ncurses

Ubuntu / Debian:

```bash
sudo apt update
sudo apt install libncurses-dev
```

## Сборка

Если все исходные файлы находятся в каталоге `src`, выполните:

```bash
gcc src/*.c main.c -Iinclude -lncurses -o snake
```

## Запуск

```bash
./snake
```

## Правила игры

Управляйте змейкой и собирайте еду (`$`), чтобы увеличивать её длину и набирать очки.

Игра заканчивается, если змейка:

* врезается в стену;
* сталкивается с собственным телом.

## Система очков

За каждую съеденную еду начисляется 10 очков.

Формула подсчета:

```text
(score) = (длина змейки - начальная длина) × 10
```
